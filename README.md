# ЭнтероФон — Мониторинг перистальтики и дневник моторики ЖКТ

Веб-приложение для врачей и клинических исследователей, предназначенное для объективного мониторинга акустической активности кишечника (фоноэнтерографии), ведения структурированного врачебного дневника перистальтики, анализа аудиосигналов и построения графиков динамики моторики ЖКТ.

---

## Клиническая и научная база

Приложение спроектировано с опорой на современные протоколы неинвазивного акустического мониторинга кишечных шумов (включая оценку тяжести острого панкреатита по классификации Атланта 2012, наблюдение за послеоперационным парезом и подбор энтерального питания):

- **5 ключевых акустических параметров** кишечных шумов:
  1. **Частота возникновения шумов** (`соб/мин`)
  2. **Доминирующая частота** (`Гц`)
  3. **Длительность события** (`с`)
  4. **Амплитуда сигнала** (`дБ`)
  5. **Межшумовой интервал** (`с`)
- **Контроль качества сигнала и сегментация**: разделение валидных кишечных шумов, физиологической тишины, дыхательных шумов, артефактов трения/движения, речи и исключённых фрагментов.
- **Клинические шкалы**: поддержка фиксации оценок по шкалам **Атланта 2012 (MAP / MSAP / SAP)**, **AGI (I–IV)**, **APACHE II**, **Ranson**, **BISAP**, а также лабораторных маркеров (СРБ, амилаза).

## Основные возможности

### 1. Картотека пациентов и клинические профили
- Предзаполненные клинические случаи (острый панкреатит с риском SAP, восстановление после абдоминальной операции, лёгкий панкреатит MAP, СРК-Д).
- Поиск по ФИО, номеру истории болезни, отделению и диагнозу, фильтрация по статусу моторики (`Норма`, `Гипо/Парез`, `Гипер`).
- Регистрация новых пациентов с сохранением данных в `localStorage`.

### 2. Мониторинг и графики активности кишечника
- Карточки 5 акустических параметров с расчётом дельты за последние 6 часов и ориентирами нормы.
- Интерактивный SVG-график динамики с переключением временного окна (`6 ч`, `12 ч`, `24 ч`, `48 ч`, `Весь период`) и выбором отображаемого параметра.
- Выделение коридора физиологической нормы (`6–18 соб/мин`) и зоны риска пареза (`< 3 соб/мин`), наложение отметок из дневника врача и перекрёстный курсор с точными значениями на каждый час.
- Суточный циркадный профиль активности (00:00–23:00) и диаграмма структуры аудиосигнала.

### 3. Врачебный дневник перистальтики
- Журнал наблюдений с указанием типа записи (*Аускультация*, *Питание / ЭП*, *Терапия*, *Симптоматика*, *Фоноэнтерография*).
- **Встроенный 60-секундный счётчик-таймер аускультации** у постели больного с кнопкой фиксации шумов (`+1 Шум`) и автоматическим расчётом частоты (`соб/мин`).
- Учёт симптомов (боль по ВАШ 0–10, вздутие живота, отхождение газов, стул, тошнота/рвота), нутритивной поддержки (`мл/ч`) и интервенций (опиоидная/эпидуральная анальгезия, прокинетики, инфузионная терапия, антибиотики).
- Автоматическая синхронизация новых записей с графиком активности кишечника и экспорт дневника в CSV.

### 4. Акустический анализатор (Web Audio DSP)
- Загрузка аудиозаписей (`.wav`, `.mp3`, `.ogg`), захват звука в реальном времени с микрофона или контактного датчика и 4 встроенных калибровочных пресета с воспроизведением.
- Полосовая фильтрация сигнала (`100–950 Гц`), сегментация эпизодов по огибающей RMS, расчёт 5 акустических параметров, построение осциллограммы и частотно-временной БПФ-спектрограммы (`0–1200 Гц`).
- Перенос вычисленных параметров напрямую в новую запись дневника пациента.

### 5. Клинический отчёт и экспорт данных
- Сводный протокол мониторинга с таблицей динамики 5 параметров, шкалами тяжести и хронологией дневника.
- Печать / сохранение в PDF (`@media print`) и экспорт данных в **CSV** (с UTF-8 BOM для корректного открытия кириллицы в Excel) и **JSON**.

## Технологический стек

- **Frontend:** React 19, TypeScript, Vite 8
- **Стилизация:** Tailwind CSS v4, Lucide React
- **Визуализация и DSP:** SVG-графики, HTML5 Canvas, Web Audio API (`AudioContext`, БПФ-спектрограмма, полосовая фильтрация)
- **Хранение данных:** `localStorage` (клиентская персистентность с возможностью экспорта/импорта)

## Быстрый старт

### Требования
- Node.js `>= 20`
- npm или bun

### Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <URL_вашего_репозитория>
cd <папка_проекта>

# 2. Установить зависимости
npm install

# 3. Запустить сервер разработки (http://localhost:3000)
npm run dev
```

### Доступные скрипты

| Команда | Описание |
| --- | --- |
| `npm run dev` | Запуск сервера разработки Vite на порту `3000` |
| `npm run build` | Сборка production-бандла в каталог `dist/` |
| `npm run preview` | Предпросмотр собранной production-версии |
| `npm run lint` | Проверка типов TypeScript (`tsc --noEmit`) |
| `npm run clean` | Очистка артефактов сборки (`dist`) |

## Дисклеймер

Программное обеспечение предназначено для исследовательской работы и поддержки клинического наблюдения. Показатели акустического анализа носят вспомогательный характер и должны интерпретироваться лечащим врачом в совокупности с клинической картиной и стандартами оказания медицинской помощи.
